# Parametrische SVG-Säcke – Version 3

Diese Version übernimmt beide vom Nutzer überarbeiteten SVGs als neue Master-Referenzen.

## Übernommene Änderungen

### Saatgutsack
- überarbeitete Schleifen / Verschnürung
- angepasstes Blattmotiv
- verschobene untere Falten
- zusätzliche obere Konturlinie über dem Blattmotiv
- angepasste mittlere Konturlinie

### Düngersack
- überarbeitete obere helle Innenfläche gemäß neuer Master-SVG

## Dateien
- `sack-generator-v3.js` – aktualisierter Generator
- `sack-seed-v3.svg` – Beispielausgabe Saatgutsack (320x420)
- `sack-fertilizer-v3.svg` – Beispielausgabe Düngersack (320x420)
- `sack-demo-v3.html` – Demo
- `master-seed-reference.svg` – hochgeladene Master-Referenz Saatgutsack
- `master-fertilizer-reference.svg` – hochgeladene Master-Referenz Düngersack

Die Generatorlogik bleibt parametrisch für die Sackform. Die dekorativen Elemente und Referenzpfade wurden an die hochgeladenen Master-Dateien angepasst.
