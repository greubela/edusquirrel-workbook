Parametrische SVG-Säcke

Breite und Höhe werden unabhängig verändert. Der Sack wird dabei geometrisch neu aufgebaut: Körperflächen dehnen sich, während Knoten, Konturen, Embleme und Granulate proportional bleiben.

Parameter

Empfohlener Gestaltungsbereich: Seitenverhältnis etwa 0,45 bis 1,8. Für extremere Formen sollte eine zusätzliche Silhouettenvariante verwendet werden.

Vorschau

Dieselbe Variante in drei Formaten

240 × 520
320 × 420
460 × 300
Minimaler Einbau in eine Webanwendung 
<script src="sack-generator-v3.js"></script>
<div id="sack"></div>
<script>
  SackGraphics.mount('#sack', {
    width: 460,
    height: 300,
    kind: 'seed' // oder 'fertilizer'
  });
</script>
